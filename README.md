# Модель городского транспорта Воронежа (Java)

Проект по курсу Объектно-Ориентированного Программирования (ООП на Java 17).

## Основные сущности
- `Stop` — неизменяемый остановочный пункт (с переопределением equals/hashCode).
- `Route` — маршрут следования с валидацией интервалов хода.
- `Trip` — конкретный рейс с расчётом времени прибытия на k-ю остановку.
- `TransportType` — перечисление видов транспорта (скорость, вместимость).
- `TransportSystem` — диспетчерская система: расписание, интервалы (headway), поиск маршрутов (прямые и с 1 пересадкой).

## Сборка и запуск
1. Запуск тестов JUnit 5:
```bash
mvn test
```
